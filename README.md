1. Hardware Requirements
To ensure the Aero-style gradient renders smoothly and the UI fits your screen, the following hardware is recommended:

CPU: 1.0 GHz Single-Core (Minimum); 2.0 GHz Dual-Core (Recommended). The CPU handles the real-time drawing of the background gradient lines.

RAM: 512 MB Minimum (The app uses ~50-70 MB, but requires overhead for the Python runtime).

GPU: Not required. All interface elements are rendered via the CPU using the Tkinter Canvas engine.

Storage: ~250 MB free space (Includes space for the Python interpreter and standard libraries).

Display: Minimum resolution of 1280 x 1024. Since the window size is fixed at 1100x900, smaller screens (like 720p) may cut off the input bar.

2. Software Requirements
LouisAI 2 is built to be cross-platform but requires specific environments to function correctly:
Python Version: Python 3.6 or higher.
Operating Systems:
Linux: Fully supported on Kubuntu and KDE Plasma desktops. (Requires python3-tk package).
Windows: Windows 7, 10, or 11.
macOS: macOS 10.11+.
Required Libraries:
tkinter (GUI Framework)
threading (For non-blocking web searches)
urllib & re (For the search engine backend)

math (Important: You must add import math to the top of the script to enable the Math Matrix functions).

Network: Active internet connection required for the "THINK" search functionality.
